# Источники обучения для Data Scientist Junior+ / Middle-

> **Цель:** подготовка к позиции Data Scientist Junior+ / Middle- за 3–4 месяца. Приоритет — русскоязычные книги, лекции, статьи, видео и практические задания.

Для подготовки я рекомендую использовать не десятки разрозненных курсов, а несколько системных источников, желательно от специалистов, которые сами работают с данными в крупных компаниях.

Среди доступных материалов есть бесплатные ресурсы от Яндекса, Авито и Stepik, а также платные симуляторы GoPractice и Karpov.Courses.

**Важное уточнение:** универсального учебника, по которому обучается большинство Data Scientist, нет. Однако есть широко используемые материалы и инструменты — именно их стоит взять за основу.

## Кратко: что я рекомендую

| Направление | Основной источник | Практика |
|---|---|---|
| SQL | Stepik — «Интерактивный тренажёр по SQL» | PostgreSQL + SQL Academy |
| Математика | Яндекс — «Математика для анализа данных» | Python, NumPy, задачи |
| Математическая статистика | Stepik — «Основы статистики» + Авито — «Прикладная статистика» | SciPy, statsmodels |

Большинство основных материалов бесплатны. Платные варианты рассмотрены отдельно.

## 1. SQL: что именно изучать

**Мой выбор: SQL на PostgreSQL.**

SQL — язык запросов, а PostgreSQL — конкретная система управления базами данных, поддерживающая SQL.

Для этой цели PostgreSQL будет удачной основной платформой. Он позволяет освоить стандартные конструкции SQL, оконные функции, запросы к аналитическим таблицам и подключение Python.

Позднее достаточно адаптироваться к диалектам ClickHouse, Greenplum, BigQuery или Spark SQL в зависимости от вакансии. Изучать все эти системы с нуля сейчас не нужно.

### Основной курс

**[Интерактивный тренажёр по SQL — Stepik](https://stepik.org/course/63054/promo)**  
**Стоимость:** бесплатно.

Один из самых массовых русскоязычных курсов: более 500 тысяч зарегистрированных учащихся, около 170 интерактивных задач. Подходит для формирования базы SQL.

Здесь стоит изучать синтаксис с самого начала, даже если некоторые операции уже знакомы. Но цель не в сертификате, а в самостоятельном написании запросов.

### Практический тренажёр

**[SQL Academy — тренажёр](https://sql-academy.org/ru/trainer)**

Содержит задачи различной сложности, включая задания в стиле технических собеседований. Есть бесплатный базовый курс и отдельные продвинутые платные программы.

### Что установить на компьютер

| Инструмент | Назначение | Ссылка |
|---|---|---|
| PostgreSQL | Основная СУБД для локальной практики | [Скачать для Windows](https://www.postgresql.org/download/windows/) |
| DBeaver Community | Графический редактор SQL-запросов и баз данных | [Скачать](https://dbeaver.io/download/) |

Дополнительно: [официальная документация PostgreSQL на русском](https://postgrespro.ru/docs/postgresql/current/tutorial).

### Насколько глубоко изучать SQL?

| Уровень | Темы | Приоритет |
|---|---|---|
| Основы | `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING` | Обязательно |
| Объединения | `INNER JOIN`, `LEFT JOIN`, подзапросы, `EXISTS` | Обязательно |
| Продвинутый SQL | `CTE`, `CASE`, `COALESCE`, `NULLIF` | Обязательно |
| Оконные функции | `ROW_NUMBER`, `RANK`, `LAG`, `LEAD`, `SUM OVER` | Обязательно |
| Аналитические запросы | Retention, воронки, когорты, агрегаты по датам | Обязательно |
| Работа с БД | Первичные ключи, связи, индексы, `EXPLAIN` | Базовое понимание |
| Администрирование | Репликация, бэкапы, тонкая настройка сервера | Не сейчас |

**Срок:** 2–3 недели для основного прохождения плюс регулярная практика до собеседований.

**Критерий освоения:** самостоятельно написать запрос, рассчитывающий Retention пользователей по недельным когортам, используя несколько таблиц, `CTE` и оконные функции.

Для позиции Junior+ это гораздо полезнее, чем знание редких команд PostgreSQL наизусть.

## 2. Математика: насколько глубоко изучать?

Важно разделить **математику для понимания ML** и **математическую статистику для работы Data Scientist**.

У них есть общие темы, но разное практическое назначение:

- Линейная алгебра и математический анализ помогают понимать работу моделей и оптимизацию.
- Теория вероятностей и математическая статистика помогают оценивать неопределённость, проверять гипотезы, интерпретировать результаты и проектировать эксперименты.

Для Junior+/Middle- уверенное знание статистики важнее, чем умение выводить сложные формулы нейросетей.

### Основной источник № 1: математика для ML

**[Яндекс — «Математика для анализа данных»](https://contest.yandex.ru/tracks/math/)**  
**Стоимость:** бесплатно.

Русскоязычный хендбук от Яндекса, разработанный совместно с ФКН ВШЭ. Содержит линейную алгебру, математический анализ, теорию вероятностей и задачи с Python.

Рекомендую выбрать его основным источником математической базы и проходить **не полностью, а выборочно**.

| Раздел | Что изучать | Глубина |
|---|---|---|
| Линейная алгебра | Векторы, матрицы, скалярное произведение, нормы, собственные значения, SVD/PCA | Уверенно |
| Математический анализ | Производные, частные производные, градиент, цепное правило, оптимизация | Уверенно |
| Теория вероятностей | Условная вероятность, формула Байеса, случайные величины, основные распределения | Уверенно |
| Комбинаторика | Перестановки, сочетания, подсчёт вероятностей | Основы |
| Теория графов | Базовые определения и алгоритмы | По необходимости |
| Строгие доказательства | Абстрактные пространства, сложные теоремы, глубокий спектральный анализ | Отложить |

**Практический критерий:** понимать, что такое градиент и почему алгоритм меняет веса модели, как интерпретировать распределение признака и почему PCA использует линейную алгебру.

### Основной источник № 2: математическая статистика

**[Основы статистики — Stepik](https://stepik.org/course/76/promo)**  
**Стоимость:** бесплатно.

Известный вводный курс: более 300 тысяч зарегистрированных учащихся, 29 уроков и около четырёх часов видео.

**Нюанс:** курс записан давно, и авторы сами предупреждают о некоторых неточностях. Поэтому рекомендую его **для первоначального понимания терминов и проверки себя**, но не как единственный источник по статистике.

### Для углубления: прикладная статистика от Авито

**[Открытый курс «Прикладная статистика» — Академия Аналитиков Авито](https://avito.tech/education/statistics)**  
**Стоимость:** бесплатно; видеолекции и код.

В курсе есть теория статистических критериев, мощность, MDE, доверительные интервалы, Z-test, T-test, метод Монте-Карло, бутстрап и работа с ratio-метриками. Опубликованы видеоматериалы и практические ноутбуки.

Также доступен **[GitHub с материалами и ноутбуками Python](https://github.com/avito-tech/applied_statistics)**.

Именно курс Авито я считаю наиболее подходящим **прикладным источником для этой подготовки**. Но начинать его удобнее после основ вероятностей и статистики.

### Математические темы, которые нужно освоить обязательно

| Тема | Что нужно уметь |
|---|---|
| Математическое ожидание | Вычислять и интерпретировать |
| Дисперсия, стандартное отклонение | Оценивать разброс и неопределённость |
| Основные распределения | Различать Bernoulli, Binomial, Normal, Poisson |
| Закон больших чисел и ЦПТ | Понимать применимость и ограничения |
| Выборка и генеральная совокупность | Различать параметры и статистики |
| Доверительные интервалы | Строить и правильно объяснять |
| Статистические гипотезы | Формулировать H₀ и H₁ |
| p-value | Корректно интерпретировать |
| Ошибки I и II рода | Объяснять последствия |
| Мощность и размер выборки | Рассчитывать для базовых случаев |
| T-test, Z-test, χ² | Выбирать при подходящих предпосылках |
| Bootstrap | Оценивать неопределённость через ресемплирование |
| Корреляция и регрессия | Понимать связь и её ограничения |

На строгие доказательства всех формул тратить месяцы не нужно. Но понимать предпосылки, применять методы и замечать некорректные выводы необходимо.

**Срок:** ориентировочно 60–90 часов суммарно на целевое повторение математики и статистики. Практика A/B затем дополнительно закрепит эти знания.

## 3. Продуктовая аналитика: что изучать?

Продуктовую аналитику нельзя сводить к списку метрик вроде DAU, MAU и LTV.

Главный навык: **научиться понимать, почему показатель изменился, что это означает для бизнеса и как проверить гипотезу об улучшении продукта.**

### Основной источник: GoPractice

**[GoPractice](https://gopractice.ru/)**

Это русскоязычная экосистема материалов по продуктовой аналитике. Для начала рекомендую бесплатные статьи:

- **[Когортный анализ. Метрики продукта и роста — GoPractice](https://gopractice.ru/product/cohort_analysis/)**. О когортах, удержании и различии между ростом аудитории и реальным улучшением продукта.
- **[Что такое продуктовые метрики и какими они бывают — Яндекс Практикум](https://practicum.yandex.ru/blog/chto-takoe-produktovye-metriki-i-kakimi-oni-byvayut/)**. Метрики, AARRR, North Star Metric и дерево метрик.

### Если нужен единый структурированный курс

**[GoPractice — Симулятор управления продуктом на основе данных](https://gopractice.ru/course/pm/)**  
**Стоимость:** платно.

Программа по продуктовому контексту с практикой в аналитической системе Amplitude. Ориентировочная длительность — около двух месяцев.

Курс прежде всего ориентирован на управление продуктом. Для интенсивной подготовки Data Scientist проходить всю программу необязательно.

### Что освоить

| Блок | Основные темы |
|---|---|
| Пользователи | DAU, WAU, MAU, stickiness |
| Конверсия | CR, CTR, воронки |
| Удержание | Retention, Churn, когортный анализ |
| Монетизация | ARPU, ARPPU, LTV, CAC, ROI |
| Экономика | Unit economics, маржинальность |
| Аналитическая система | Event tracking, `user_id`, `session_id`, event timestamps |
| Продуктовые решения | NSM, дерево метрик, сегментация, гипотезы |
| Визуализация | Дашборды, сравнение когорт, динамика показателей |

Для практики советую взять условный маркетплейс или мобильное приложение. Подготовить SQL-запросы для расчёта Retention, conversion rate, LTV и построить небольшой дашборд.

Можно использовать PostgreSQL + Python, а для визуализации познакомиться с [Yandex DataLens](https://datalens.yandex/).

**Срок:** 20–30 часов изучения концепций плюс практический SQL-кейс. Этого достаточно для уверенной базы, а не для глубокого продуктового опыта.

### Альтернатива с более близкой к работе аналитика практикой

**[Karpov.Courses — Симулятор аналитика](https://karpov.courses/simulator)**  
**Стоимость:** платно.

Это двухмесячный симулятор, включающий работу с ClickHouse, Redash, Superset, Airflow, продуктовые метрики, A/B-тесты и статистику. Он рассчитан на людей, уже знакомых с Python, SQL и базовыми статистическими методами.

Если выбирать один платный курс для практики аналитики, он ближе к рабочим задачам Data Scientist, чем большой курс по продуктовому менеджменту.

## 4. A/B-тестирование: как изучать с нуля и где практиковаться?

Это направление рекомендую начинать **после основ математической статистики**, а не параллельно с первым знакомством с p-value.

### Главный источник

**[Академия Аналитиков Авито — курс по прикладной статистике](https://avito.tech/education/statistics)**

Статистика и A/B-тестирование тесно связаны. Для начала изучай первую часть курса: гипотезы, статистическая мощность, доверительные интервалы, Z-test, T-test, MDE, Монте-Карло.

Затем переходи к практической статье:

**[Методичка по A/B-тестированию от аналитиков Авито](https://habr.com/ru/companies/avito/articles/936804/)**

В ней разобран полный процесс эксперимента на прикладном примере, включая ошибки дизайна, выбор метрики, проверку статистической значимости и представление результата. Есть сопутствующий код.

### На какой платформе работать?

Для изучения A/B-тестов **специальная коммерческая платформа не нужна**.

На первом этапе вся практика выполняется в Python. Подойдут привычные VS Code и Jupyter Notebook.

| Инструмент | Назначение |
|---|---|
| `pandas` | Загрузка и обработка данных эксперимента |
| `NumPy` | Численные расчёты и симуляции |
| `SciPy` | Статистические критерии |
| `statsmodels` | Доверительные интервалы, проверка гипотез, мощность тестов |
| `matplotlib` | Графики распределений и результатов |
| PostgreSQL | Выгрузка и агрегация событий пользователей |

В [документации `statsmodels`](https://www.statsmodels.org/stable/) есть функции для расчёта доверительных интервалов, сравнения пропорций и мощности тестов.

### Как выглядит полноценная практика A/B-теста?

1. **Гипотеза.** Например, новый интерфейс увеличит конверсию в покупку.
2. **Дизайн.** Выбрать основную метрику, единицу рандомизации, α, мощность, MDE и рассчитать размер выборки.
3. **Разделение.** Случайно назначить пользователей в контрольную и тестовую группы.
4. **Проверка данных.** Проверить корректность распределения групп, в том числе SRM, дубли и пропуски.
5. **Анализ.** Посчитать эффект, доверительный интервал и подходящий статистический тест.
6. **Решение.** Оценить статистическую и практическую значимость, риски и рекомендовать внедрение либо отказ.

**Важно:** платформа для запуска эксперимента и инструмент для статистического анализа результатов выполняют разные функции. Коммерческие платформы управляют назначением пользователей в группы и показом вариантов продукта. Python позволяет проанализировать данные. Пока нет собственного продукта с трафиком, достаточно публичного датасета или симуляции.

### Первый датасет для практики

**[Mobile Games A/B Testing — Cookie Cats (Kaggle)](https://www.kaggle.com/datasets/mursideyarkin/mobile-games-ab-testing-cookie-cats)**

Это данные эксперимента в мобильной игре, где сравнивались два варианта расположения игрового ограничения (на уровнях 30 и 40). Есть информация об удержании пользователей, числе сыгранных раундов и принадлежности к экспериментальной группе.

На этом датасете можно сделать полноценный проект: исследование данных, сравнение удержания, проверка гипотез и итоговая рекомендация.

После этого переходи к симуляциям A/A-тестов, bootstrap, CUPED, ratio-метрикам и множественным проверкам гипотез.

### Нужен ли платный курс по A/B?

**[Симулятор A/B-тестов — Karpov.Courses](https://karpov.courses/simulator-ab)**  
**Стоимость:** платно.

Есть базовая и продвинутая программы, включая практику на Python.

Но на старте не стоит покупать его автоматически. Бесплатной программы Авито и самостоятельной практики достаточно, чтобы заложить сильную основу. Платный симулятор имеет смысл, если после этого останутся пробелы в дизайне экспериментов и сложных статистических методах.

## 5. Как встроить источники в 4-месячное обучение

| Период | Основная задача | Учебный источник |
|---|---|---|
| Недели 1–2 | SQL и основы математики | Stepik SQL + Яндекс Хендбук |
| Недели 2–3 | Вероятности и статистика | Stepik «Основы статистики» |
| Недели 3–4 | Прикладная статистика | Курс Авито, часть 1 |
| Неделя 5 | Продуктовые метрики и SQL | GoPractice + SQL Academy |
| Неделя 6 | Дизайн и анализ A/B-тестов | Авито + Jupyter |
| Недели 7–8 | Продуктовый ML-проект | SQL, CatBoost, статистика |
| Недели 9–12 | Углубление и прикладные кейсы | Повторение по пробелам |
| Недели 13–16 | Итоговый проект и техническая практика | Собственные проекты |

SQL нужно продолжать тренировать практически ежедневно хотя бы по 30–45 минут. Статистику следует повторять через реальные задачи, а не перечитывать лекции целиком.

**Главный совет:** не пытаться одновременно полностью пройти Stepik, Яндекс, GoPractice и курсы Авито. Каждый источник должен выполнять конкретную функцию.

Оптимальная связка для подготовки к Junior+/Middle-:

**Классический ML (основной учебник) + SQL (Stepik/PostgreSQL) + математика (Яндекс) + статистика и эксперименты (Авито) + продуктовая практика (GoPractice/собственный проект).**

Это даст фундамент гораздо ближе к задачам реального Data Scientist, чем ещё один набор ML-библиотек без SQL, статистики и понимания бизнес-эффекта.
