### Обработка временного признака

Если известна только дата, то можно закодировать признак как число дней с момента наблюдений, если известно еще и время - то число секунд с момента наблюдений.

Временной признак позволяет учесть тренд (рост/падение популярности с течением времени). Помимо этого можно учитывать еще и сезонность, что позволит получить более точно аппроксимировать значения. Сезонность можно выделять номером дня/недели/месяца и тд. Также можно просматривать внутредневную сезонность (номер часа).

### Кодирование категориального признака (Эмбеддинг)

1. Порядковое кодирование #ordinal_encoding (кодируем признак по тому порядку, который представлен по умолчанию в df). **Не рекомендуется использовать**, т.к. модель при обучении будет учитывать порядок, тогда как нумерация на самом деле была произвольная + будет ложное представление о близости значений.

2. Частотное кодирование #frequency_encoding (кодируем в зависимости от частоты признака среди всего количества признаков, например, Хлеб - 1/3, Сыр - 1/3, Хлеб - 1/3). Полезность определяется в зависимости от того, наксколько частота встречаемой категории связана с целевой переменной.

3. Однократное/фиксированное кодирование #one-hot_encoding, #dummy encoding (признак кодируется вектором размера К дискретных значений). Например, Хлеб - [0, 0, 1], Сыр - [0, 1, 0]. Из плюсов - кодирование признаков однозначное, т.к. попарное расстояние между признаками одинаковое. Минус кодировки - при большом количестве признаков вектор становится слишком большим. Но это можно нивелировать минусы путем **регуляризации**. По факту добавляются новые столбцы. **При кодировании должны быть обработаны пропуски.**

```python
from feature_engine.encoding import OneHotEncoder
one = OneHotEncoder(variables=['Sex','Embarked'])
df_train = one.fit_transform(df_train)
```

4. Кодирование средним #mean encoding, #target encoding (признак кодируется средним ожидаемым откликом в рамках одной категории). Для регрессии находим средние значения в рамках одной категории, для классификации среднее находим в рамках частот. Такой способ **максимально информативен для предсказывания отклика по кодировке**. **Вместе с этим подобная кодировка ведет к переобучению модели**, тк мы фактически указываем моделе какие результаты мы должны получить. Это можно нивелировать при помощи #leave_one-out_encoding - кодирование признака осуществляется средним в рамках одной категории, **не учитывая при этом значение того признака для которого высчитываем target**. + можно кодировать категорию средним значением по другой категории, чтобы максимально избежать зависимостей.

### Кодирование циклического признака

#cyclic_encoding
Циклические значения - час в сутках, день в месяце и тд (при этом нужно учитывать грань цикла - для часов: 23 час будет близок к 1 часу ночи и т.д.). Моделирование подобныз значений происходит при помощи циклического кодирования, где признак $u \in [0; \max(u))$ кодируется парой вещественных значений:

$$
u \to [\sin\big(\frac{2\pi}{\max(u)}\big), \cos\big(\frac{2\pi}{\max(u)}\big)]
$$
