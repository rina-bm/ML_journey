Прогностическая (прогнозная функция) - это функция $f(x)$ которая по известным признакам будет выдавать прогнозы отклика $\hat{y}$ и т.к. объекты многообразны, то правила выбираются из семейства функций $f_w(x)$, где $w$ - это настраиваемые моделью параметры (веса модели). Например, $f_w​(x)=w_0​+w_1​x_1​+w_2​x_2​+⋯+w_D​x_D​$. Это **линейная регрессия**.
$\hat{y} = f_w​(x)$

Пример:
$цена = w0 + w1*площадь + w2*этаж + w3*возраст\_дома$ - w0, w1... - это веса модели.
#loss_function

Чтобы понять, насколько хорошо были подобраны веса - считаем функцию потерь, которая зависит от прогноза и целевой переменной ($L(\hat{y}, y)$). Эту функцию необходимо минимизировать.
для регрессии есть 2 функции:

квадрат ошибки (L2) $(\hat{y} - y)^2$

модуль ошибки (L1) $|\hat{y} - y|$

это все приводит к $x$ - это ошибка предсказаний ($x =\hat{y} - y$).
Также используется **функция Хубера** (smooth L1 loss) - для минимизации выбросов. Ошибки могут быть как маленькими, так и большими. И есть ошибка маленькая - используется MSE ($x^2$ квадрат ошибки, к маленьким ошибкам относимся строго), если ошибка большая - то MAE ($|x|$, из-за больших ошибок не драматизируем). Сама функция:

$$
L(x) =
\begin{cases}
0.5x^2, & |x| < \beta \\
\beta(|x| - 0.5\beta), & |x| \ge \beta
\end{cases}
$$

$\beta > 0$ - это гиперпараметр, который определяет, где заканчивается квадратичная граница и начинается линейная. Гиперпараметры не настраиваются по обучающей выборке, они задаются пользователем или подбираются моделью по валидационной выборке.

Для задачи классификации функции потерь более сложные, ну суть в двух словах - найти поверхность, которая разделит пространство на несколько частей (это или линия, или монстр из нейросети и тд). Основные функции потерь для задач классификации и регрессии - выпуклые (у выпуклой ф-и может не быть минимума + у выпуклой ф-и мб несколько минимумов).

Необходимо, чтобы модель работала не только на обучающихся данных, но и на тестовых, причем для новых данных необходимо минимизировать число ожидаемых потерь. Это называется **теоретический риск** (средняя ошибка модели на всех возможных новых данных):

$$
\iint L(f_w(x), y)\, p(x,y)\, dx\, dy
$$

где $p(x, y)$ - это настоящее распределение данных, которое мы не знаем (у нас есть только обучающая выборка ($x_1,y_1) ..., (x_n,y_n)$), поэтому на практике находим $w$ с помощью минимизации **эмпирического риска** (средняя ошибка модели на обучающей выборке):

$$ L(w) = \frac{1}{N} \sum\_{n=1}^{N} L\left(f_w(x_n),\, y_n\right) $$

т.е. для каждого объекта считаем ошибку модели и берем среднее.

Модель с уже настроенными параметрами - алгоритм прогнозирования.
